# Harbor authorship

The Harbor mesh geometry, UV layout, manufacturing details, procedural recipe and CPU QA setup are original PARASITE project work. No downloaded models, photographs, logos, fonts or third-party surface maps were introduced by this kit.

`CityGatePilot_SharedPBR` and its original procedural atlas images are reused unchanged from `ArtSource/CityGatePilot/CityGatePilot.blend` and `Textures/CityGatePilot_{A,N,M}.png`; their original source hashes are retained in the manifests. The existing gate package's authorship note applies to those images. No new runtime PBR textures are created. The runtime district also reuses the project's existing Riverside ferry, river shader, reflection owner and world-text font; this source package does not redistribute additional external assets.

Blender 4.5.16 LTS performed the actual CPU authoring, FBX export/import and review rendering. The Blender executable is not bundled. Project-authored output follows the repository's licensing terms; this note introduces no independent third-party licence or broader ownership claim.
