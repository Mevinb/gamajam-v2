# Lake source provenance

The old `ArtSource/Cinematics/EndingFilm.blend` is opened read-only. Its packed
LakeGirl humanoid, skin/eye/hair/clothing maps, shore, bench, jetty, stones, reeds,
sun and physical water remain the source basis. Their existing project credits
are retained in `Docs/THIRD_PARTY_ASSETS.md`.

The inland planting reuses existing project files read-only:

| Existing input | Origin | Licence |
|---|---|---|
| `Assets/Parasite/Art/City/Foliage/Trees/TreePlane.fbx`, `TreeLinden.fbx` | Original procedural branch/leaf-card geometry generated by `Tools/blender/environment/trees.py` | Project original geometry |
| `BarkPlane_albedo.jpg` | Bark Platanus, Dimitrios Savva — https://polyhaven.com/a/bark_platanus | CC0 1.0 |
| `BarkLinden_albedo.jpg` | Bark Brown 02, Rob Tuytel — https://polyhaven.com/a/bark_brown_02 | CC0 1.0 |
| `TreeLeavesGreen_albedo.png`, `TreeLeavesLight_albedo.png` | Existing project leaf-cluster atlases composed from ambientCG LeafSet 024 / 014 / 007 / 027, Lennart Demes — https://ambientcg.com/ | CC0 1.0 |
| `Assets/Parasite/Art/City/Props/shrub_04/` FBX, diffuse and mask | Shrub 04, Rico Cilliers — https://polyhaven.com/a/shrub_04 | CC0 1.0 |

All reused texture images are packed into every saved source that needs them.
No network download is required by the authoring script. No source asset above
is changed. These credits repeat the project's existing asset register rather
than asserting a new licence investigation.

The authored camera shots, girl performance, periodic wind/water keyframes,
park planting layout, inland ground extension, far bank, 42 original distant
human silhouettes, green-eye mask and two-beat chest signals are created by
`Tools/blender/cinematics/full_story/lake_story/author_lake.py`.

Arrival and the loop contain no branch-only signals. Peace contains no green
iris shader or heartbeat population. Those assets are added exclusively to
Dominion, which the integration contract permits only after explicit choice.
