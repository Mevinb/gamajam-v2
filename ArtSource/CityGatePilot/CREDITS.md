# City gate pilot authorship

All exported meshes, UV layout, atlas images and procedural surface patterns in this package are original project work authored by `Tools/blender/city_gate_pilot/author_gate.py`, seed 731405. No external photographs, generated reference images, downloaded PBR maps, fonts, logos or third-party mesh libraries were used in these exported assets.

The existing PARASITE gate placement, physical box dimensions and motion are reused from this project's `CityBuilder`, `WorldKit`, `CityLayout` and `AccessDoor` source; their exact hashes are retained in `physical-contract.json`. That reference does not imply those files were changed. The existing game's sign, camera, warning light and security-booth assets are not bundled into this FBX.

Blender 4.5.16 LTS was used as the authoring/export/render tool. The packed blend contains the original atlas images and the original QA ground/camera/lights. No Blender executable or external font is redistributed in this package. The CPU preview images are authoring QA, not native gameplay captures.

These project-authored files follow the repository's licensing terms; this note introduces no separate third-party licence or unsupported ownership claim for the rest of the game.
