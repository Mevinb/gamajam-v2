# Far Shore dialogue sources

Eight original island dialogue lines were synthesized locally with cached Kokoro-82M v1.0 weights on CPU, using two threads and disabled network access. The production manifest retains the actual voice profiles, tool/source hashes, clip keys and full-stream decode/level measurements. These are synthesized voices, not human actor recordings. Existing 59 voice catalogue entries were preserved; the eight clips extend the catalogue to 67.

The actual OGG files live under `Assets/Parasite/Resources/Audio/Voice`; exact text, cast and source ownership live in `Assets/Parasite/Audio/voice_manifest.json`. Technical audio/key checks pass for all eight. Seven focused Editor cases now pass using real FMOD source sample progression across all eight clips: arrival, both branch refuge/roster cues and both departures, including finite clearing, skip and disabled/missing fallback. Subjective listening and built-player playback remain pending. Arrival uses a monotonic clock so scene-loading time cannot shorten a new cue; departure keeps its original 2.5-second motion and holds for the remaining spoken window. These source changes are newer than the retained 0.5.0 preview and do not change its binary.

Exact offline regeneration is pinned by `Tools/audio/island_voice_lines.json` and the dry-by-default `Tools/audio/gen_island_voice.py`. Use the existing audio venv and a fresh ignored Logs output directory; `--go` is required to synthesize. No dependencies are installed and no live asset is overwritten. Reference audio hashes must be checked and any environment-dependent drift reviewed before publication.
