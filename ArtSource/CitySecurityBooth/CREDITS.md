# City security booth authorship

The booth mesh, UV layout, manufactured detail geometry, author recipe and QA setup are original PARASITE project work. No external models, photographs, downloaded surface maps, fonts, logos or AI-generated reference images were added.

The material and three original atlas images are appended unchanged from the project's `ArtSource/CityGatePilot/CityGatePilot.blend` and verified against `ArtSource/CityGatePilot/Textures/CityGatePilot_{A,N,M}.png`. Their exact source hashes are recorded in the production and verification manifests. The existing gate package's authorship note also applies to those reused images. This package introduces no new texture images or third-party asset licences.

The booth placement and solid-body, roof and window dimensions come from the existing project contract. The original Unity `SECURITY` text, physics, navigation and behavior are not included in this FBX. Blender 4.5.16 LTS was used for authoring, FBX export/import and CPU review rendering; no Blender executable is redistributed.

These project-authored files follow the repository's licensing terms. This note does not establish separate licensing or ownership for other game assets. Review images are CPU authoring QA, not native gameplay captures.
